# StyleShop — учебный магазин одежды на Go

Каталог, корзина, заказы и служебная панель магазина одежды. Сохранены название StyleShop, розово-фиолетовая палитра, карточки товаров, шесть товаров и восемь фотографий из исходного проекта. Серверная часть и клиентские сценарии приведены к функциональности эталонного проекта практики.

## Запуск

Нужны Go 1.24 или новее и C-компилятор для SQLite-драйвера (CGO). На macOS используется Command Line Tools, на Linux — GCC; на Windows нужен GCC/MinGW в PATH.

Распакуйте архив и откройте терминал **в папке с go.mod**:

```sh
go run ./cmd/setup
go run ./cmd/server
```

Откройте **http://127.0.0.1:8082**. Порт 8082 выбран, чтобы проект можно было запускать рядом с другим магазином. Изменить порт можно в `.env`.

На macOS также можно открыть `start.command`, на Windows — `start.bat`. Остановка сервера — Ctrl+C.

`cmd/setup` создаёт `.env` со случайным секретом сессий и не перезаписывает существующий файл. При первом запуске автоматически создаются база `data/styleshop.db`, три демонстрационных аккаунта и оригинальный каталог. Повторный запуск сохраняет изменения.

Кнопка с именем открывает профиль. «Заказы» открывает историю покупателя, «Панель» — служебные разделы.

## Функции

- Поиск по названию, описанию и бренду; фильтры по типу, размеру, цвету, бренду, полу и сезону. Можно выбрать несколько значений, сбросить фильтры, отсортировать цены.
- Карточка товара, галерея и увеличение фото, выбор размера и количества с учётом остатка.
- Регистрация с подтверждением пароля, обязательными телефоном и согласием; проверка почты и российского номера телефона.
- Профиль с отдельным редактированием имени, почты, телефона и пароля. После смены пароля сессии отзываются.
- Корзина: изменение количества, удаление, выбор отдельных позиций и оформление выбранного. Остальные товары остаются в корзине.
- Заказ: последовательный номер, дата, состав, сохранённая цена, сумма, статусы и история отмены.
- Покупатель может отменить свой заказ до готовности к выдаче; сотрудник указывает обязательную причину отмены. Отменённый заказ остаётся в истории.
- Остатки списываются при оформлении и возвращаются при отмене ровно один раз. Проверки и запись выполняются в транзакции.
- Администратор создаёт товары с несколькими размерами, цветами и остатками по вариантам, редактирует характеристики, добавляет несколько PNG/JPEG и удаляет фото.
- Удаление товара скрывает его из каталога и сохраняет историю заказов.
- Управление пользователями и ролями; системные и используемые роли защищены.
- Адаптивное оформление для телефона и компьютера, клавиатурное управление и сообщения об ошибках.

## Технологии и структура

Go `net/http`, `database/sql`, SQLite, bcrypt, серверные сессии, HTML/CSS/JavaScript без сборщика и сторонних фронтенд-зависимостей. Логи — JSON через `slog`. SQL-миграции и интерфейс встроены в бинарный файл.

```text
cmd/server          запуск HTTP-сервера
cmd/setup           создание локальной конфигурации
internal/config     переменные окружения и .env
internal/httpapi    маршруты, проверки прав и обработчики
internal/store      SQLite, миграции и каталог StyleShop
internal/testsupport  искусственный каталог только для тестов
migrations          схема, роли и обновления базы
web/static          интерфейс и исходные фотографии StyleShop
docs                API, сравнение функций и результаты проверки
```

Цены API хранятся и передаются **в копейках** целым числом: 225000 = 2 250 ₽. Начальный каталог из старого проекта автоматически конвертирован из рублей. Сезоны «весна»/«осень» приведены к «Демисезон», «всесезон» — к «Круглогодичный».

Новая версия использует собственную схему базы и серверные сессии вместо прежнего JWT. Старые `store.db`, `.env`, аккаунты и демонстрационные заказы из архива не переносятся; исходный архив остаётся отдельной резервной копией. Не подменяйте новую базу старым файлом. В комплекте чистые исходники: только каталог и фото, без чужих контактов, паролей и истории заказов.

## Проверка

```sh
go test -race ./...
go vet ./...
node --check web/static/app.js
go build -o bin/styleshop ./cmd/server
```

Тесты используют временные базы, проверяют права, транзакции, профиль, частичное оформление, отмены, остатки, фото и повторный запуск. Данные рабочего магазина не меняются.

Полный список 27 методов задания и дополнительные маршруты: [docs/API.md](docs/API.md). Сопоставление функций: [docs/FUNCTIONS.md](docs/FUNCTIONS.md).

## Ограничения

Это учебный магазин: онлайн-оплата, реальная доставка и рассылки не подключены. Первое скачивание Go-зависимостей требует интернета. В деморежиме используются общедоступные учебные аккаунты. Реальные пароли и рабочая база не должны попадать в репозиторий; `.env`, `data/`, `uploads/` и `bin/` исключены через `.gitignore`.
