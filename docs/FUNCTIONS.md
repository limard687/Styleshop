## Сохранено из исходного StyleShop

Название, фирменная палитра, баннер, боковые фильтры, белые карточки, скруглённые элементы и адаптация к телефону. Исходные шесть товаров, восемь фото, UUID, цены и остатки сохранены в стартовом каталоге. Для сезона «всесезон» используется «Круглогодичный», для весны и осени — «Демисезон».

## Изменения устройства проекта

Вместо двух пересекающихся точек запуска из архива оставлен один сервер `cmd/server`. Серверная логика объединена в `internal/httpapi`, база — в `internal/store`. Вместо JWT используются отзываемые серверные сессии. Пользовательский интерфейс использует общий клиент для всех разделов.

Рабочая база создаётся заново: история пробных заказов и контакты старых аккаунтов не включены в исходники. Исходный архив не изменялся. Публичная публикация, оплата и рассылки не выполнялись.
